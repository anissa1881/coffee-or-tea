Entry for the make.fun bounty **One Letter: Coffee or Tea**
(`u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`).

The program writes exactly one letter to `/output/entry.txt`: **A** for
coffee (or B for tea). This entry chooses **A — coffee**. No word, no
explanation, no punctuation — just the single letter the judge reads.

Run it with Node 22:

```sh
node main.ts
```

The output directory comes from `MAKEFUN_OUTPUT_DIR`, falling back to the
`output` folder next to the script.
